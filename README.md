# 锦囊

365 个小主意：冷场的时候翻一张。

一个装在手机主屏幕上、断网也能用的家庭小应用。像刷短视频一样上下滑，每一张都是一件能马上用的小事：
一句打开话头的问题、一个两三个人围着一部手机就能玩的小对决、一道一起解的题、一个让人“哇”一声的小东西、
一件放下手机去做的事，或者一条只给爸爸看的提示。

**打开：** <https://zenglingdingblue-ui.github.io/jinnang/>

## 装到手机上

- **iPhone / iPad：** 用 Safari 打开上面的地址 → 点底部的「分享」→「添加到主屏幕」。
- **安卓：** 用 Chrome 打开 → 菜单 →「安装应用」或「添加到主屏幕」。

第一次打开时联网，全部内容会缓存到手机里；之后在车上、飞机上、山里都打得开。

## 怎么用

- **上下滑**换卡片。每天第一张是「今日锦囊」，一年 365 天各不相同。
- **救场**（底部中间的按钮）：冷场了，点一下，马上给你一张两分钟内、零准备就能用的。
- **我看 / 一起看**（左上角）：自己翻的时候用「我看」，卡片上会多一条只给爸爸的提示；
  把手机递给孩子、或者放在三个人中间时，切到「一起看」，这些提示和只给爸爸看的卡片都会藏起来。切回「我看」要长按。
- **发现**里可以按类型、按场景找，也有「工具箱」：计分板、转盘、计时器这些可以直接用。

## 里面有什么

| 类型 | 张数 | 是什么 |
|---|---|---|
| 话匣子 | 70 | 一句话打开话头：二选一、如果、让他教你 |
| 一起玩 | 50 | 手机上的小对决、小游戏 |
| 烧脑 | 50 | 一起解一道题 |
| 给他看 | 50 | 让人“哇”一声的知识和小模拟 |
| 一起做 | 55 | 放下手机做的小事 |
| 三人局 | 25 | 三个人一起的 |
| 锦囊 | 65 | 只给爸爸看的提示，都有出处 |

其中 39 个互动组件（算 24 点、反应对决、球场计分板、你画我猜、三门问题、投篮物理、如果地球是一个篮球……）都在一部手机上就能玩。

## 几句说明

- **不说教。** 给孩子看的内容没有“教育意义”的尾巴，好玩就是全部目的。
- **不收集任何东西。** 没有账号、没有统计、不联网上传；收藏和记录只存在这台手机里。
- **有出处。** 给家长的提示都标了来源和证据的强度；有的是研究，有的只是专家经验或个案，照实标注。
- **不替代专业意见。** 健康与发育相关的内容只是家长读物，不替代医生面诊。

## 开发

纯静态站点，没有框架，没有构建依赖（只需要 Python 3 跑合并脚本）。

```
index.html  manifest.webmanifest  sw.js
css/        base.css（设计令牌） app.css（外壳） theme.css（皮肤） widgets-*.css
js/         core.js（公共能力与组件注册表） app*.js（外壳） widgets/*.js（互动组件）
content/    卡片源文件（JSON）
assets/     图标、贴纸插画
tools/      build.py（合并卡片、生成离线清单） validate_cards.py（校验） selftest.sh（组件自测）
dev/        测试台与各模块的测试
docs/       SPEC.md（产品与接口规格） DESIGN.md（视觉规范）
```

```bash
python3 tools/validate_cards.py content/*.json   # 校验卡片
python3 tools/build.py --strict                  # 生成 data/cards.js、js/sprites.js、precache-manifest.js
bash tools/selftest.sh                           # 无头浏览器把每个组件挂载、乱点、销毁一遍（需要本机装有 Chrome）
python3 -m http.server 8766                      # 本地预览：http://localhost:8766/
```

加一张卡片：在 `content/` 里对应的文件加一条，字段见 `docs/SPEC.md` 第 3 节，然后重新构建。
加一个互动组件：照 `js/widgets/basic.js` 的样子写，用 `JN.registerWidget` 注册。
