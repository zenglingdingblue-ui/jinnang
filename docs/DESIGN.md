# 锦囊 · 设计说明

> 视觉设计师 V1 维护。对应的文件：`assets/icons.svg`、`assets/favicon.svg`、四张应用图标 PNG、`css/theme.css`。
> 接口以 `docs/SPEC.md` 为准；这一页讲「长什么样、为什么、别人怎么接」。

## 1. 一句话

**一只装着 365 个小主意的金色锦囊。** 给孩子看的那一面像球衣和海报：深而饱和的整屏颜色、一张出血的大贴纸、很大的字；
只给爸爸看的那一面像锦囊本身：深蓝的绸面、金线、不动。两面靠同一种金色连着——彩色卡片的皮肤里，金色只给了「爸爸提示」。

## 2. 颜色

| 用途 | 取值 | 说明 |
|---|---|---|
| 锦囊金 `--accent` | `#ffd166`（没改） | 品牌色。金色的层次：高光 `#fff3cf` · 亮 `#ffe7a6` · 本色 `#ffd166` · 暗 `#eaa838` · 绳 `#b46a12` |
| 类型底色 `--c-*-a / -b` | 见第 3 节，**全部加深了** | 是「底色」，上面压白字。原来的亮色压白字大多不够（2.5–4.4:1）；现在每一个都 ≥ 4.6:1 |
| 类型亮色 `--c-*-hi` | 见第 3 节，**新增、可选** | 给「压在深色界面上的字、细线、小图标」用（在四种深色底上都 ≥ 4.5:1）。用法：`var(--c-talk-hi, var(--c-talk-a))` |
| `--on-color-2` | 白 86%（原 82%） | 彩色底上的次要文字 |
| 中性色、状态色、玩家色 | 没改 | |

两条规矩：**白字只压在底色（a / b）上，不压在亮色上；类型色要当文字或细线用，取 `-hi`。**
加深以后，用 `--c-*-a` 在深色画布上画线的组件会比原来暗（约 2.9–4.2:1，看得见但不亮），想要原来的亮度就换成 `-hi`。

## 3. 七个颜色世界

每张卡片 = 整屏渐变（a → b）+ 对角换一点色相 + 贴纸背后一盏柔光 + 一层同色暗纹。相邻卡片的渐变方向、柔光颜色、贴纸倾斜角都不一样，所以连着刷有节奏。

| 类型 | 底色 a → b（白字对比度） | 亮色 hi | 柔光 | 对角色相 | 暗纹 `pat-*` | 贴纸倾斜 |
|---|---|---|---|---|---|---|
| 话匣子 talk | `#d43b10` → `#c21650`（4.7 / 6.0） | `#ff7a45` | 橙 | 玫紫 | 引号、气泡、问号 | +8° |
| 一起玩 play | `#2b66f0` → `#6238e0`（4.9 / 6.6） | `#6f95ff` | 电光青 | 紫 | 十字键、圆钮、折线 | −8° |
| 烧脑 puzzle | `#8a3fe0` → `#3b1e98`（5.4 / 11.5） | `#a98bff` | 淡紫粉 | 靛蓝 | 连成网的拼图齿 | +6° |
| 给他看 show | `#04808c` → `#0b5fc2`（4.7 / 6.1） | `#00b8a9` | 水青 | 靛紫 | 星芒、行星轨道 | −7° |
| 一起做 do | `#14863a` → `#0b6a57`（4.7 / 6.5） | `#2fb36a` | 嫩绿 | 青蓝 | 虚线路线、脚印、定位针 | +10° |
| 三人局 trio | `#d8267f` → `#982dc0`（4.7 / 6.1） | `#ff66ad` | 蜜桃 | 靛蓝 | 三角、三个圆 | −5° |
| 锦囊 insight | `#1b2a4a` → `#0d162b`（14.2 / 18.0） | `#ffd166` | 金，很淡 | — | 金色回纹，7% | +4° |

**锦囊是例外**：绸面上两道斜向的反光；贴纸是金色、小一号（最多占宽 46%），外面套两圈金色细线，像一枚印；类型徽标是金线框；
标题是暖白 `#fff3d1`；页脚上方一道金色缝线；主按钮金底深字；**背景不动**。

对比度是量出来的，不是估的：预览页上 46 组文字（标题按大字 ≥ 3:1，其余 ≥ 4.5:1）全部达标；
另外单独扫过背景——**贴纸包围盒以外，白字压在哪里都 ≥ 4.7:1**（柔光动画的两端都量了）。所以只要字不压在贴纸上，对比度就不用再操心。

## 4. 卡片皮肤怎么搭的（`css/theme.css`）

从下到上：`.card__bg`（渐变 + 顶部、底部压暗）→ `::before` 暗纹 → `::after` 柔光 → `.card__art` 贴纸 → 文字和部件。
背景和贴纸用负的 `z-index` 垫在下面，所以 theme.css 给 `.card` 加了 `isolation: isolate` 和 `overflow: hidden`（贴纸要出血）。

- **暗纹**用这个世界里最深的颜色印（27%），不是白线：压在它上面的字对比度只升不降；上半截清楚，到文字那里淡下去。
- **柔光**的圆心跟着贴纸走，直径是贴纸的 1.6 倍，出了贴纸的包围盒就基本没了。它是唯一会动的东西（14 秒来回，只动 transform 和 opacity）；
  `prefers-reduced-motion` 时完全静止，`prefers-contrast: more` 时暗纹和柔光都去掉。
- **贴纸**：白色、95% 不透明、带投影，在右上角出血 7%。大小不是固定比例，而是 `clamp(下限, 屏高的几成 − 这种形态的文字要占的高度, 上限)`：

  | 形态 | 贴纸宽度（百分比相对卡片宽） | 390×844 时 |
  |---|---|---|
  | plain | `clamp(36%, 60dvh − 240px, 62%)` | 62% |
  | either | `clamp(34%, 50dvh − 200px, 62%)` | 57% |
  | steps | `clamp(30%, 45dvh − 160px, 60%)` | 56% |
  | reveal | `clamp(28%, 55dvh − 260px, 56%)` | 52% |
  | quiz | `clamp(24%, 30dvh − 100px, 46%)` | 39% |
  | widget | `clamp(26%, 50dvh − 290px, 38%)` | 34% |

  系数是在真外壳里拿全部 365 张卡片、12 种手机尺寸（320×568 到 430×932）量出来的：每种尺寸上，标题、正文、按钮蹭到贴纸包围盒的
  卡片不超过 5%，外壳判成 `.is-crowded`（贴纸退成水印）的只有 0–4 张。外壳的版面大改以后，这张表要重新量（`dev/shots/v1/artfit.py --search`）。
- **没有贴纸**时外壳用类型图标顶替（`class="card__art jn-ic"`）：自动变成 1.5 粗的半透明线稿，像印在布上的水印。
- **给外壳的五个旋钮**（设在 `.card` 上，柔光跟着走）：`--jn-art-size` `--jn-art-top`（默认 13%）`--jn-art-right`（默认 −7%）`--jn-art-tilt` `--jn-art-opacity`（默认 0.95）。
- 颜色世界的变量（`--k-ink` 白底上的字色、`--k-deep` 最深色、`--k-glow`、`--k-pat` …）挂在 `[data-type]` 上，卡片以外也取得到；外壳要用请带兜底值。

## 5. 图标与花纹的画法（`assets/icons.svg`）

**线性图标 `i-*`（61 个：界面 46 + 类型 7 + 场景 8）**
- 24 格，2px 描边，圆头圆角，不填充；活动区 2–22：圆 r = 9，方 4–20、圆角 3–4。symbol 里不写 `stroke` / `fill`。
- 小圆点用零长线段 `M12 12h.01`（直径 2），或 r = 1 的圆（直径 4）。**不要用 r < 1 的圆**：描边比直径还粗时，中间会漏出一个洞。
- `-fill` 实心版：外轮廓和线性版的描边外沿重合；勾是镂空的（透出底色），不是另一种颜色。
- 拿不准时的取舍：`rescue` 是闪电（救生圈留给场景 `s-rescue`）；`check` 是带圈的勾，才能和 `check-fill` 成对；`eye-off` 是闭上的眼睛；
  `saved` 是书签；`share` 箭头向上出盒子，`install` 箭头向下进托盘；四个「转圈」的各有特征：`refresh` 两段箭头、`replay` 圈里带三角、`rotate` 带一个小方块、`undo` 是折回的箭头。
- 类型图标彼此不撞形：气泡、手柄、拼图块、闪光、鞋印、三点三角、束口袋。

**品牌图形 `g-*`**（自带颜色，放在 `--bg` / `--surface` 上）：`g-logo` 120 格；三张引导图、两张安装示意 240×180。安装示意只有线框和步骤号，没有任何商标。

**花纹 `pat-*`**：200 格、可平铺，线宽 2.5，`currentColor` + 16% 不透明度。元素不跨边；非跨不可的（拼图、回纹）在对边补一份。
theme.css 里用的是同一份线稿转成的 data URI（当蒙版，颜色由 CSS 定）。改了花纹要重新生成：取 symbol 里的内容，去掉那个 `opacity`，
`currentColor` 换成 `#fff`，包成 200 格的 `<svg>` 做 URL 编码，替换 theme.css 里 `PAT:BEGIN / PAT:END` 之间对应的那一行（我用的脚本是 `dev/shots/v1/pat2css.py`）。

## 6. 应用图标

- 一只束口的锦囊：扇口三瓣（中间一瓣更亮）、束口处一道缝（负形，不画绳子）、饱满的袋身、身上一颗镂空的四角星。小到 29px 也认得出。不带字。
- 底色是深蓝的**竖直**渐变 `#21356a → #15223f → #0b1226`（只用竖直方向：每一行一个颜色，512 的 PNG 从 160 KB 降到 42 KB）。
- `favicon.svg` 是矢量源（512 格，满铺、不带圆角）。锦囊高度：普通版约 67%；maskable 版 59%，整个落在中间 60% 的安全区里。
- PNG：512（42 KB）、512-maskable（37 KB）、192（3.6 KB）、apple-touch 180（3 KB），都不透明、不带圆角。

## 7. 给外壳工程师

外壳现在的版面已经和这套皮肤对上了（徽标在左上、贴纸在右上、文字贴底、`--jn-art-*`、`.is-crowded`）。下面是打磨时的依据。

**分区与留白**
- 顶栏下面一行是徽标（左上，最宽占 58–62%），右上是贴纸；标题、正文、操作、提示、页脚贴底；右侧操作列只占下半截。
- 徽标行和标题之间的那片空当**什么都不要放**——那是贴纸和颜色喘气的地方，短卡片显得大方全靠它。
- 各块之间 12–14px；页脚和标签栏之间留 10px 以上。

**大小**
- 标题：字重 800，行高 1.15，最多三行。9 个字以内 40–44px，10–14 个字 34px，再长 28–30px（现在的 `data-tl` 分档很好）。
- 正文 18px / 1.6，纯白，不用 `--on-color-2`；小屏 16px / 1.5。徽标 12.5px / 600。页脚 12px。
- 主按钮高 54（`.jn-btn--lg`），收紧时不低于 46；可点的东西不小于 44。

**层次（从强到弱）**：标题 → 白底主按钮 → 贴纸 → 正文 → 徽标 → 爸爸提示 → 页脚。一张卡片只有一处白底主操作（二选一的两个选项算一处）。

**还可以更好的三处**
1. 拥挤判定现在四周各让 18%，贴纸是实心的时候，文字还是可能蹭到贴纸的边。建议收到 8% 左右，并且「先缩后淡」：先把 `--jn-art-size` 设成算出来的空当，缩到原来的六成还放不下，再退成水印。
2. 选择题的对错现在用整块的绿和红。「一起做」是绿的世界、「话匣子」是红的世界，色块会被吃掉。建议：选对 = 白底 + 类型色的字（`--k-ink`）+ `check-fill`；选错 = 保持线框 + `close`，其余选项降到 45%。
3. 类型入口、列表里如果把类型色当文字或小图标用，换成 `--c-*-hi`。

**不要做的事**：金色要省着用（现在是爸爸提示、今日徽标、救场按钮、已选中的收藏和做过，够了，别再加）；不要给卡片加圆角描边或彩色边条；
不要给文字加渐变；不要用表情符号顶替图标。

## 8. 怎么自查

`dev/shots/v1/`（不进仓库）里有我用的脚本：`preview.py` 生成静态预览页，`contrast.py` 量对比度，`tokens.py` 核对令牌，
`artfit.py` 在真外壳里量贴纸和文字撞不撞，`tidy.py` 核对图标清单，`icon.py` 导出应用图标，`pat2css.py` 生成花纹。
改皮肤以后至少跑前两个，再截图看一眼；要长期留着的话，请负责人挑几个挪进 `tools/`。
